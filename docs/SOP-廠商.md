# 廠商操作 SOP

適用角色：廠商  
系統網址：https://xin-guan-li-xi-tong.vercel.app

## 1. 登入

1. 開啟系統網址。
2. 輸入廠商帳號與密碼。
3. 點選「登入」。
4. 登入後主要使用「廠商工作台」。
5. 廠商帳號只能看到指派給自己的案件。

## 2. 查看新案件

1. 進入「廠商工作台」。
2. 查看案件清單。
3. 可使用篩選：
   - 廠商
   - 狀態
   - 只看需回覆
4. 若有新案件提示，優先打開查看。
5. 廠商讀取案件後，系統會同步更新相關人員看到的案件狀態。

## 3. 查看案件內容

1. 在廠商工作台點開案件。
2. 查看基本資料：
   - 案件編號
   - 案件類型
   - 標題
   - 辦公地點
   - 回寄地點
   - 申請人
   - 說明
3. 查看品項細項：
   - 品項名稱
   - 規格
   - 數量
   - SN 號碼
   - 問題描述
4. 查看照片或附件。

## 4. 回覆案件

1. 打開案件明細。
2. 進入回覆區。
3. 填寫處理進度或需補充資料。
4. 點選送出或儲存。
5. 儲存成功後，案件建立者與相關負責人會收到未讀通知。

## 5. 需要內部補資料時

1. 在案件回覆中明確寫出需要補充的內容。
2. 例如：
   - SN 不清楚
   - 照片不足
   - 規格不完整
   - 需確認回寄地點
3. 儲存回覆後，系統會通知相關人員。

## 6. 填寫回寄資訊

1. 案件處理完成後，打開案件明細。
2. 填寫回寄單號。
3. 若可選擇回寄地點，確認地點正確。
4. 儲存案件。
5. 儲存後狀態會更新為廠商已寄出。

## 7. 液晶面板補料

1. 打開液晶面板申請案件。
2. 查看累計品項清單。
3. 依本次補料內容勾選對應 SN 或品項。
4. 填寫：
   - 補料日期
   - 貨櫃號碼
   - 備註
5. 儲存補料資料。
6. 已補料品項會收合到已補料清單，避免清單過長。

## 8. 廠商不會看到的案件

以下案件不會出現在廠商工作台：

- 尚未審核通過的維修料品申請。
- 未指派給該廠商的案件。
- 已被刪除的案件。

## 9. 操作注意事項

- 上傳附件或儲存案件後，請等待系統顯示成功提示。
- 不要連續重複按上傳或儲存。
- 若附件上傳失敗，重新整理後再試一次。
- 若案件資料有誤，請用回覆通知內部人員修正。

## 10. 每日檢查清單

- 是否有新案件。
- 是否有需回覆案件。
- 是否有逾期或急件。
- 是否有已修回但尚未填寫回寄單號案件。
- 是否有液晶補料需要對應 SN 或貨櫃號碼。
