# 管理者操作 SOP

適用角色：系統管理者  
系統網址：https://xin-guan-li-xi-tong.vercel.app

## 1. 登入

1. 開啟系統網址。
2. 輸入管理者帳號與密碼。
3. 點選「登入」。
4. 登入後確認左側選單可看到：
   - 儀表板
   - 回覆通知
   - 新增案件
   - 案件總表
   - 時效提醒
   - 廠商工作台
   - 地點申請統整
   - 貨櫃批次
   - 催廠商清單
   - 統計報表
   - 匯入 / 匯出
   - 基本資料設定
   - 操作紀錄

## 2. 儀表板查看

1. 進入「儀表板」。
2. 查看今日新增統計：
   - 順豐送修
   - 貨櫃送修
   - 維修料品申請
   - 液晶面板申請
   - 程式 BUG 回報
   - 補料
3. 查看「今日/近期需追蹤」。
4. 若有逾期、急件、廠商未回覆案件，點案件進入明細處理。

## 3. 帳號與權限設定

1. 進入「基本資料設定」。
2. 找到帳號權限清單。
3. 確認帳號狀態：
   - 啟用：可登入系統。
   - 停用：不可登入系統。
4. 設定角色：
   - 管理者：可管理帳號、基本資料、刪除案件、查看操作紀錄。
   - 作業員：可建立與處理案件。
   - 廠商：只能處理指派給該廠商的案件。
   - 查看者：只查看資料，不建立或修改案件。
5. 設定五大模組主要負責人：
   - 順豐送修負責人
   - 貨櫃送修負責人
   - 維修料品申請負責人
   - 液晶面板申請負責人
   - 程式 BUG 回報負責人
6. 維修料品申請需審核時，審核人員必須由管理者在帳號權限中設定。

## 4. 辦公地點設定

1. 進入「基本資料設定」。
2. 找到辦公地點區塊。
3. 新增地點時填寫：
   - 辦公地點名稱
   - 負責人
4. 負責人建議從已建立帳號的人員清單選取。
5. 如地點名稱或負責人異動，使用編輯功能更新。
6. 若案件回寄到其他地點，系統會依回寄地點通知相關負責人。

## 5. 廠商資料設定

1. 進入「基本資料設定」。
2. 找到廠商資料區塊。
3. 新增或編輯廠商名稱與聯絡資訊。
4. 若有廠商帳號，確認該帳號已綁定正確廠商。
5. 廠商只能看到自己被指派的案件。

## 6. 建立案件

1. 進入「新增案件」。
2. 選擇案件類型：
   - 順豐送修
   - 貨櫃送修
   - 維修料品申請
   - 液晶面板申請(保固內)
   - 程式 BUG 回報
3. 填寫標題、地點、廠商、申請人、說明與相關日期。
4. 依案件類型填寫品項或設備資訊。
5. 上傳必要照片或附件。
6. 點選建立案件。
7. 確認系統出現成功提示。

## 7. 維修料品申請審核

1. 作業員建立維修料品申請後，案件會先進入審核流程。
2. 管理者或被設定為維修料品負責人的人員會收到審核通知。
3. 進入通知或案件明細查看申請內容。
4. 審核通過：
   - 案件進入正式總表流程。
   - 廠商才會看到案件。
5. 審核不通過：
   - 填寫不通過原因。
   - 系統通知建立人修正。

## 8. 液晶面板申請與補料

1. 進入「新增案件」。
2. 案件類型選擇「液晶面板申請(保固內)」。
3. 填寫申請標題。
4. 新增液晶品項：
   - SN 號碼
   - 問題描述
   - 設備照片
5. 同標題液晶申請會視為同一筆案件累計品項。
6. 廠商補料時，進入案件明細。
7. 在補料登記中勾選本次補料對應的品項。
8. 填寫補料日期與貨櫃號碼。
9. 儲存後確認品項移入已補料清單。

## 9. 通知處理

1. 左側「回覆通知」出現紅色數字時，代表有待處理通知。
2. 點進「回覆通知」查看通知案件。
3. 廠商回覆後，案件建立者與相關負責人會收到通知。
4. 案件回寄到不同地點時，回寄地點負責人也會收到通知。
5. 管理者可查看所有案件，但未讀通知仍以相關責任人為主。

## 10. 案件刪除

1. 進入「案件總表」。
2. 打開案件明細。
3. 只有管理者或案件建立者可以刪除案件。
4. 刪除案件前確認：
   - 案件不再需要追蹤。
   - 附件與照片不需保留。
5. 刪除後，相關通知與附件會一併清除。

## 11. 匯出 Excel

1. 進入「匯入 / 匯出」或案件總表相關匯出功能。
2. 選擇要匯出的資料範圍。
3. 點選匯出 Excel。
4. 下載後打開檔案確認格式正常。

## 12. 每日檢查清單

- 儀表板今日新增統計是否正常。
- 是否有待審核維修料品申請。
- 是否有逾期或急件。
- 是否有廠商未回覆案件。
- 是否有液晶補料尚未對應品項。
- 是否有帳號需要停用或調整權限。
