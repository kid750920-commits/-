# 作業員操作 SOP

適用角色：作業員  
系統網址：https://xin-guan-li-xi-tong.vercel.app

## 1. 登入

1. 開啟系統網址。
2. 輸入帳號與密碼。
3. 點選「登入」。
4. 登入後確認左側可看到常用功能：
   - 儀表板
   - 回覆通知
   - 新增案件
   - 案件總表
   - 時效提醒
   - 催廠商清單
   - 地點申請統整
   - 貨櫃批次
   - 統計報表

## 2. 建立一般案件

1. 進入「新增案件」。
2. 選擇案件類型：
   - 順豐送修
   - 貨櫃送修
   - 維修料品申請
   - 液晶面板申請(保固內)
   - 程式 BUG 回報
3. 填寫基本資料：
   - 案件標題
   - 優先度
   - 辦公地點
   - 廠商
   - 申請人
   - 說明
4. 需要回寄到其他地點時，選擇正確回寄地點。
5. 上傳必要附件或照片。
6. 點選建立案件。
7. 確認系統出現成功提示。

## 3. 建立維修料品申請

1. 進入「新增案件」。
2. 案件類型選擇「維修料品申請」。
3. 填寫申請內容與品項資料。
4. 送出後案件會先進入審核。
5. 審核通過前，廠商不會看到案件。
6. 若審核不通過，查看通知內的不通過原因。
7. 依原因修正後重新送出或更新案件內容。

## 4. 建立液晶面板申請

1. 進入「新增案件」。
2. 案件類型選擇「液晶面板申請(保固內)」。
3. 填寫申請標題。
4. 新增液晶資料：
   - SN 號碼
   - 問題描述
   - 設備損壞照片
5. 若同一批申請有多筆設備，逐筆新增品項。
6. 同標題案件會累計在同一筆液晶申請內。
7. 儲存後到案件總表確認資料是否出現。

## 5. 查看案件總表

1. 進入「案件總表」。
2. 使用搜尋或篩選找到案件。
3. 點開案件查看：
   - 基本資料
   - 品項細項
   - 回覆紀錄
   - 附件照片
   - 操作紀錄
4. 若案件由自己建立，可依權限修改或刪除。
5. 若案件不是自己建立，只可依權限查看或協助補充資料。

## 6. 回覆與通知

1. 左側「回覆通知」有紅色數字時，代表有待讀訊息。
2. 點進「回覆通知」。
3. 打開案件查看廠商或內部回覆。
4. 讀取後，符合條件的未讀通知會消失。
5. 自己建立的案件不以自己操作標記已讀，需由相關通知對象讀取或流程完成後扣除。

## 7. 催廠商

1. 進入「催廠商清單」。
2. 查看急件、逾期或長時間未回覆案件。
3. 打開案件確認目前狀態。
4. 在回覆區補充催覆內容。
5. 儲存後確認案件狀態與通知正常更新。

## 8. 貨櫃批次

1. 進入「貨櫃批次」。
2. 查看貨櫃送修案件與品項完成度。
3. 依貨櫃號碼或廠商篩選。
4. 打開案件確認寄出、回寄與處理狀態。

## 9. 地點申請統整

1. 進入「地點申請統整」。
2. 選擇辦公地點或處理狀態。
3. 查看該地點維修料品申請彙整。
4. 若資料未出現，先確認案件是否已審核通過。

## 10. 案件狀態

系統會依操作自動調整狀態：

- 廠商讀取案件後，相關人員狀態會更新為廠商處理中。
- 內部需要廠商回覆時，狀態會更新為待廠商回覆中。
- 廠商填寫回寄單號後，狀態會更新為廠商已寄出。
- 廠商回覆後，建立者或相關負責人會收到通知。

## 11. 每日檢查清單

- 是否有自己的未讀通知。
- 是否有建立案件被退回需修正。
- 是否有逾期或需催廠商案件。
- 是否有液晶申請品項需要補照片或 SN。
- 是否有回寄地點選錯需要修正。
